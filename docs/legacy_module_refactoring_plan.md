# Legacy模块重构计划

## 概述

本文档记录了`monitoring_legacy`模块的重构计划，该模块包含已弃用的类型和API，需要逐步迁移到新的`system_monitor`模块。

## 当前状态

### 已弃用的类型

- `MetricType` - 已弃用，应使用`system_monitor::PerformanceMetrics`替代
- 相关使用位置：28处警告

### 影响范围

1. **monitoring_legacy.rs** - 定义已弃用类型
2. **monitoring/mod.rs** - 重新导出已弃用类型（向后兼容）
3. **多个使用位置** - 使用已弃用类型的代码

## 迁移优先级

### 高优先级
- 新功能开发必须使用新API
- 性能关键路径的代码

### 中优先级
- 现有功能的维护和更新
- 测试代码

### 低优先级
- 很少修改的遗留代码
- 内部工具代码
