# 架构决策记录 (ADR)

本目录包含游戏引擎的架构决策记录 (Architecture Decision Records)。

## ADR 模板

每个 ADR 应包含以下部分：

1. **标题**：简短、描述性的标题
2. **状态**：提议、已接受、已弃用、已替代
3. **背景**：驱动此决策的背景和问题陈述
4. **决策**：所做的决策及其描述
5. **后果**：应用此决策的后果，包括正面和负面
6. **替代方案**：考虑的其他方案及未被选择的原因
7. **参考**：相关的链接和文档

## 提交新的 ADR

1. 创建新的 ADR 文件，命名为 `YYYY-MM-DD-[title].md`（或使用顺序号）
2. 遵循上述模板
3. 更新此 README 中的 ADR 索引
4. 提交 PR 进行审查
