# ADR-0012: 软体物理系统设计

## 状态

已接受

## 日期

2025-01-27

## 背景

现有的物理系统（基于Rapier）只支持刚体物理，不支持软体物理（如布料、流体）。许多游戏需要软体物理效果，如：
- 布料模拟（旗帜、衣服等）
- 流体模拟（水、血液等）
- 软体变形

## 决策

实现独立的软体物理系统，包括：

1. **布料模拟**
   - 基于弹簧-质点系统
   - 三种弹簧类型：结构、剪切、弯曲
   - 支持固定点和动态粒子
   - 重力和空气阻力

2. **流体模拟**
   - 基于SPH（Smoothed Particle Hydrodynamics）方法
   - 密度和压力计算
   - 粘性力计算
   - 空间分区优化

3. **系统集成**
   - ECS组件（`SoftBodyComponent`）
   - 自动更新系统
   - 与Rapier物理系统兼容

## 后果

### 正面影响

- **功能完整**: 支持软体物理效果
- **性能**: 使用空间分区优化邻居查找
- **灵活性**: 可以独立使用或与Rapier集成
- **可扩展性**: 易于添加新的软体类型

### 负面影响

- **性能开销**: 软体物理计算密集
- **内存使用**: 需要存储大量粒子数据
- **复杂性**: 增加了系统的复杂性

### 限制

- 当前实现是CPU-based，大规模模拟可能性能不足
- 与Rapier的集成需要手动实现碰撞检测
- 某些效果（如表面张力）需要进一步优化

## 替代方案

1. **使用Rapier的软体扩展**: 如果Rapier支持软体
   - 优点：统一API
   - 缺点：Rapier当前不支持软体

2. **使用第三方库**: 如Bullet Physics的软体扩展
   - 优点：功能完整
   - 缺点：增加依赖、可能不兼容

3. **当前方案**: 独立实现软体物理
   - 优点：完全控制、易于集成
   - 缺点：需要自己实现和维护

## 未来改进

1. **GPU加速**: 使用GPU进行大规模模拟
2. **更好的集成**: 与Rapier的深度集成
3. **更多软体类型**: 如软体变形、头发模拟等
