   - 代码格式验证（cargo fmt --check）
   - Clippy警告检查（cargo clippy）
   - 单元测试执行（cargo test --lib）
   - 常见错误模式检测

2. **`.git/hooks/pre-push`** - 推送前检查
   - 完整测试套件（cargo test --workspace）
   - 密钥泄露检测（扫描password、secret、api_key、token）
   - 可选性能基准测试（cargo bench）
   - 可配置的SKIP_BENCHMARK环境变量

#### 安全特性

- **防止格式问题**: 自动检测未格式化的代码
- **防止lint警告**: 零警告策略
- **防止测试失败**: 所有测试必须通过
- **防止密钥泄露**: 自动检测敏感信息

#### 使用方法

```bash
# 正常使用 - 自动执行
git commit -m "feat: add new feature"
git push

# 跳过基准测试（如需要）
SKIP_BENCHMARK=true git push
```
