# FAQ

Frequently asked questions about the game engine.

## General Questions

### Q: What is this game engine?
A: A modern, data-oriented game engine written in Rust.

### Q: Is it free?
A: Yes, it's open source under the MIT license.

### Q: What platforms are supported?
A: Windows, Linux, macOS, WebAssembly, Android, and iOS.
