## New Features at a Glance

### 1. Plugin AssetLoader System

```rust
// Define custom loader
struct MyLoader;
impl AssetLoader for MyLoader {
    fn load(&mut self, path: &Path) -> Result<Asset> { /* ... */ }
}

// Register it
manager.register_loader(Box::new(MyLoader));
```

### 2. Runtime Configuration

```rust
// Choose strategy at runtime
let config = KeyExchangeConfig::secure(); // or insecure()
let server = NetworkServer::new_with_config(config);

let strategy = ConcurrencyStrategy::DashMap; // or StdSync
let manager = EntityManager::with_strategy(strategy);
```

### 3. DashMap Integration (Optional)

```toml
[dependencies]
game_engine = { version = "0.2.0", features = ["dashmap"] }
```

## Known Issues

1. **DashMap on WASM**: Falls back to std::sync automatically
2. **Tracy Profiler**: 1-2% overhead (disable in production)
3. **Hot Reload**: Debug builds only
