## 📊 项目概览

### 技术栈

**核心技术**:
- **语言**: Rust 2024 Edition
- **渲染**: WebGPU (wgpu)
- **ECS**: bevy_ecs / 自研混合
- **物理**: Rapier3d
- **数学**: glam
- **异步**: tokio
- **音频**: 自研 + cpal
- **脚本**: 多语言支持（Lua/C#/Python/JS/TS）
- **AI**: NPU推理集成

**平台支持**:
- **桌面**: Windows、macOS、Linux
- **移动**: iOS、Android
- **Web**: WebAssembly
- **游戏机**: PS5、Xbox Series X/S、Switch
