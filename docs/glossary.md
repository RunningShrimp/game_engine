# Glossary

This document defines common terms used in the engine.

## Terms

### ECS (Entity Component System)
An architectural pattern that separates data (components) from logic (systems).

### Entity
A unique ID representing a game object.

### Component
Data attached to entities.

### System
Logic that operates on components.

### World
Container for entities, components, and systems.

### Resource
Global data shared across systems.
