## 使用场景

### 开发工作流

```bash
# 1. 开发新功能
git checkout -b feature/new-feature

# 2. 实现功能
# ... 编码 ...

# 3. 运行基准测试
./scripts/run_benchmarks.sh --compare main

# 4. 检查回归
python3 scripts/check_regressions.py

# 5. 提交PR
git push origin feature/new-feature

# 6. CI/CD自动运行基准测试并评论结果
```

### 性能优化工作流

```bash
# 1. 建立基线
./scripts/run_benchmarks.sh --save-baseline before_optimization

# 2. 实施优化
# ... 优化代码 ...

# 3. 测量改进
./scripts/run_benchmarks.sh --compare before_optimization

# 4. 生成flamegraph
cargo flamegraph --bench gpu_benchmark

# 5. 验证目标达成
# 检查报告中的指标
```
