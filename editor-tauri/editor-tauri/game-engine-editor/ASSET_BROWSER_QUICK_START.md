# 资源浏览器快速使用指南

## 快速开始

### 启动编辑器

```bash
cd /Users/wangbiao/Desktop/project/game_engine/editor-tauri/editor-tauri/game-engine-editor
npm run dev
```

### 打开资源浏览器

**方法1：快捷键**
- Windows/Linux: `Ctrl + O`
- macOS: `Cmd + O`

**方法2：工具栏按钮**
- 点击编辑器底部状态栏的"📁 Assets"按钮

## 主要功能

### 1. 浏览资源

#### 目录导航
- **左侧目录树**：点击展开/折叠文件夹
- **面包屑导航**：点击路径快速跳转
- **前进/后退**：使用顶部导航按钮

#### 视图模式
- **网格视图**：缩略图网格布局
- **列表视图**：详细列表布局
- **大图标**：更大的缩略图
- **小图标**：更紧凑的布局

### 2. 搜索和过滤

#### 搜索
- 在搜索框输入文件名
- 支持实时搜索（自动防抖）
- 搜索路径和文件名

#### 过滤
- 点击"Filter"按钮打开过滤器
- 选择资源类型（网格、纹理、音频等）
- 可多选组合过滤

#### 排序
- **按名称**：A-Z或Z-A
- **按类型**：资源类型分组
- **按日期**：修改时间排序
- **按大小**：文件大小排序
- 点击排序按钮切换升序/降序

### 3. 选择资源

#### 单选
- 单击资源项

#### 多选
- **Ctrl + Click**：切换选择
- **Shift + Click**：范围选择
- 选择状态会在右侧详情面板显示

### 4. 查看详情

- 选择资源后，右侧面板显示：
  - 资源预览（图像/模型/音频）
  - 文件名
  - 文件类型
  - 文件大小
  - 修改日期
  - 元数据（尺寸、格式等）

### 5. 管理资源

#### 右键菜单
右键点击资源显示：
- **重命名**：修改资源名称
- **复制路径**：复制资源路径到剪贴板
- **显示在Finder**：在文件管理器中显示
- **查看依赖**：查看资源引用关系
- **删除**：移到回收站

#### 工具栏操作
- **刷新**：重新加载当前目录
- **新建文件夹**：创建新文件夹
- **导入**：导入外部资源

### 6. 导入资源

#### 拖拽导入
1. 点击"导入"按钮打开导入对话框
2. 从文件管理器拖拽文件到对话框
3. 或点击"Browse Files"选择文件
4. 配置导入选项（压缩纹理、生成缩略图）
5. 点击"Import"按钮

#### 导入选项
- **压缩纹理**：自动压缩纹理文件
- **生成缩略图**：为资源生成缩略图

## 常见问题

### Q: 资源浏览器无法打开？
A: 确保开发服务器正在运行（`npm run dev`）

### Q: 看不到资源？
A: 检查Assets目录是否存在，点击刷新按钮重新加载

### Q: 导入失败？
A: 确保目标目录有写权限，检查文件格式是否支持

### Q: 预览不显示？
A: 某些资源类型暂不支持预览，这是正常的

### 扩展开发
要添加新功能，参考现有组件结构：
1. 在`types.ts`添加类型定义
2. 在`utils.ts`添加工具函数
3. 创建新的React组件
4. 在`AssetBrowser.tsx`中集成
