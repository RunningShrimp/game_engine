## 测试辅助工具

### 自定义断言 (9个)

1. `assert_approx_eq` - 浮点数近似相等
2. `assert_vec3_approx_eq` - 向量近似相等
3. `assert_completes_within` - 超时断言
4. `assert_contains` - 集合包含断言
5. `assert_string_contains` - 字符串包含断言
6. `assert_ok` - Ok断言
7. `assert_err` - Err断言
8. `assert_some` - Some断言
9. `assert_none` - None断言

### 测试工具类 (7个)

1. **Timer** - 性能计时器
   - `new()` - 创建计时器
   - `elapsed()` - 获取经过时间
   - `elapsed_ms()` - 获取毫秒数

2. **retry** - 重试机制
   - 支持自定义重试次数和延迟
   - 指数退避策略

3. **ConcurrentTestRunner** - 并发测试
   - `spawn()` - 生成测试线程
   - `join_all()` - 等待所有线程

4. **SharedState** - 共享状态管理
   - `read()` - 读取状态
   - `write()` - 写入状态
   - `update()` - 更新状态

5. **TestDataGenerator** - 测试数据生成
   - `random_range()` - 随机范围
   - `random_bool()` - 随机布尔
   - `random_string()` - 随机字符串

6. **MemoryMonitor** - 内存监控 (Linux)
   - `current_usage()` - 当前使用量
   - `delta()` - 使用量变化

7. **TestLogCollector** - 日志收集
   - `log()` - 记录日志
   - `get_logs()` - 获取所有日志
   - `contains()` - 检查包含
   - `count()` - 统计数量
