# Changelog

All notable changes to the Game Engine VS Code extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial VS Code extension structure
- LSP client integration
- Basic commands: restart LSP, show docs, open playground
- Configuration settings for LSP server
- TypeScript compilation setup

## [0.3.0] - 2026-01-02

### Added
- Initial release of Game Engine VS Code extension
- Intelligent code completion for game engine APIs
- Hover information for engine types and functions
- Go-to-definition and find all references
- Real-time diagnostics and error checking
- LSP server integration
- Debug adapter protocol (DAP) support
- Performance statistics command

### Fixed
- LSP server startup issues
- Completion trigger character support

## [0.2.0] - 2025-12-15

### Added
- Basic LSP client integration
- Document symbols support
- Workspace symbols support
- Code actions provider

### Changed
- Improved performance of symbol indexing
- Better error handling in LSP communication

## [0.1.0] - 2025-12-01

### Added
- Initial proof-of-concept
- Basic LSP server communication
- Minimal code completion support

### Added

- New capabilities
- New commands

### Changed
- Changes in existing functionality
- Performance improvements
- API changes

### Deprecated
- Features that will be removed in future releases

### Removed
- Features removed in this release

### Fixed
- Bug fixes
- Error corrections

### Security
- Security vulnerability fixes
