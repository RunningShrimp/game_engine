## 自定义快捷键

### 打开快捷键设置

1. 使用快捷键 `Ctrl+K` (或 `Cmd+K` on macOS)
2. 或通过菜单：**工具 > 快捷键设置**

### 修改快捷键

1. 在快捷键设置中找到要修改的命令
2. 点击"编辑"按钮
3. 按下新的快捷键组合
4. 点击"保存"应用更改

### 重置快捷键

- 点击"重置"按钮恢复单个快捷键为默认值
- 点击"重置所有"恢复所有快捷键为默认值

### 导出/导入配置

- **导出**：将当前快捷键配置保存为 JSON 文件
- **导入**：从 JSON 文件加载快捷键配置

### 冲突处理

如果新的快捷键与其他命令冲突：

1. **警告级别**（不同上下文）：可以共存，系统会根据当前上下文选择
2. **错误级别**（相同上下文）：需要选择禁用其中一个

## 提示和技巧

### 1. 快捷键学习模式

启用学习模式后，所有带快捷键的按钮都会显示快捷键提示。

### 2. 快捷键冲突检测

系统会自动检测快捷键冲突并提供解决方案。

### 3. 上下文感知

快捷键会根据当前激活的面板自动调整，同一快捷键可以在不同上下文执行不同操作。

### 4. 快速参考

- 按 `Ctrl+/` 随时打开快捷键参考面板
- 使用搜索功能快速查找需要的快捷键
- 按分类或上下文筛选显示

### 5. 备份配置

- 定期导出您的快捷键配置
- 系统会自动创建配置备份
- 可以在设置中查看和管理备份

## 常见问题

### Q: 为什么有些快捷键不工作？

A: 检查以下几点：
1. 快捷键是否被禁用
2. 当前上下文是否支持该快捷键
3. 是否与其他应用程序冲突
4. 快捷键是否被自定义修改

### Q: 如何恢复默认快捷键？

A: 在快捷键设置中点击"重置所有"按钮。

### Q: 可以在不同计算机间共享快捷键配置吗？

A: 可以，通过导出/导入功能在不同设备间共享配置。

### Q: 快捷键预设会覆盖我的自定义设置吗？

A: 是的，应用预设会覆盖所有当前快捷键。建议先导出备份。

### Q: 如何报告快捷键冲突？

A: 快捷键设置会自动检测冲突。如果发现未检测到的冲突，请通过问题追踪系统报告。
