# 节点式材质编辑器

一个功能完整的节点式材质编辑器，用于创建和编辑基于物理的渲染（PBR）材质。

## 功能特性

### ✅ 已实现功能

#### 1. 节点系统核心
- **节点类型**: 支持多种节点类型
  - 输入节点：纹理、颜色、浮点数、向量输入
  - 数学节点：加、减、乘、除、线性插值、混合等
  - PBR节点：PBR主节点、金属度、粗糙度、法线贴图、环境光遮蔽
  - UV节点：UV坐标、纹理映射、UV滚动
  - 纹理节点：纹理采样、纹理参数
  - 输出节点：材质输出

#### 2. 节点编辑器UI
- **无限画布**: 支持平移和缩放
- **节点面板**: 分类显示可用节点
- **节点渲染**: 带颜色编码的节点标题、输入/输出端口
- **连线绘制**: 贝塞尔曲线连接节点
- **拖拽功能**: 拖拽节点重新定位
- **端口连接**: 点击拖拽创建连线
- **断开连接**: 右键点击或点击连接线上的删除按钮
- **节点选择**: 单击选择，Shift+Click多选
- **删除节点**: Delete或Backspace键删除选中节点
- **复制粘贴**: Ctrl+C/V复制粘贴节点

#### 3. PBR材质节点
- **Texture Input**: 纹理输入节点
  - 文件路径选择
  - UV通道选择
  - 纹理类型标识

- **Color Input**: 颜色输入节点
  - RGB颜色选择器
  - Alpha通道支持

- **PBR Master**: PBR主节点
  - Base Color输入
  - Metallic输入
  - Roughness输入
  - Normal Map输入
  - Ambient Occlusion输入
  - 默认参数值

- **Math Nodes**: 数学运算节点
  - Multiply（乘法）
  - Add（加法）
  - Subtract（减法）
  - Divide（除法）
  - Lerp（线性插值）
  - Mix（混合）
  - Power（幂运算）
  - Sqrt（平方根）
  - Abs（绝对值）
  - Min/Max（最小/最大值）
  - Clamp（钳位）
  - Normalize（归一化）

#### 4. 实时预览
- **预览网格**: 支持球体、立方体、平面
- **WebGL渲染**: 使用原生WebGL渲染材质
- **实时更新**: 节点参数修改后实时更新预览
- **鼠标交互**: 拖拽旋转预览模型
- **PBR着色器**: 简化的PBR光照模型

#### 5. 材质管理
- **新建材质**: 创建空白材质
- **保存材质**: 保存到浏览器localStorage和本地文件
- **加载材质**: 从localStorage加载已保存的材质
- **材质预设**:
  - Basic（基础材质）
  - Metal（金属材质）
  - Plastic（塑料材质）
- **导出材质**: 导出为JSON格式
- **导入材质**: 从JSON文件导入材质

## 使用方法

### 基本使用流程

1. **打开材质编辑器**
   ```typescript
   import { MaterialEditor } from './components/MaterialEditor';

   function App() {
     return <MaterialEditor />;
   }
   ```

2. **创建节点**
   - 点击左侧面板中的节点类型
   - 节点会出现在画布中心

3. **连接节点**
   - 从一个节点的输出端口拖拽到另一个节点的输入端口
   - 只能连接数据类型兼容的端口
   - 每个输入端口只能有一个连接

4. **编辑参数**
   - 在节点内部直接修改参数值
   - 颜色参数使用颜色选择器
   - 浮点数参数使用数字输入框

5. **预览材质**
   - 右侧预览面板实时显示材质效果
   - 可以切换预览模型（球体、立方体、平面）
   - 拖拽预览区域旋转模型

6. **保存材质**
   - 点击工具栏的"Save"按钮或按Ctrl+S
   - 材质会保存到浏览器localStorage和本地文件

### 快捷键

- **Ctrl+S**: 保存材质
- **Ctrl+C**: 复制选中的节点
- **Ctrl+V**: 粘贴节点
- **Delete / Backspace**: 删除选中的节点
- **Escape**: 清除选择
- **Ctrl + 滚轮**: 缩放画布
- **中键拖拽 / 空格+拖拽**: 平移画布

### 节点颜色编码

不同类型的节点有不同的颜色标识：
- 🟣 紫色：纹理节点
- 🩷 粉色：颜色节点
- 🔵 蓝色：数值输入节点
- 🟠 橙色：数学运算节点
- 🟢 绿色：PBR节点
- 🔵 青色：法线贴图节点
- 🔴 红色：输出节点

## 技术实现

### 核心技术

- **React 19**: UI框架
- **TypeScript**: 类型安全
- **WebGL**: 实时材质预览
- **SVG**: 连线绘制
- **localStorage**: 本地材质存储

### 关键特性

1. **类型安全**
   - 完整的TypeScript类型定义
   - 端口数据类型验证
   - 编译时错误检查

2. **性能优化**
   - React.memo优化节点渲染
   - useCallback避免不必要的重渲染
   - 虚拟化（未来可扩展）

3. **用户体验**
   - 流畅的拖拽交互
   - 实时预览反馈
   - 直观的节点连接
   - 键盘快捷键支持

## 示例：创建一个简单的PBR材质

1. 添加一个**PBR Master**节点

2. 添加**Color Input**节点
   - 设置颜色为红色

3. 连接Color Input的输出到PBR Master的Base Color输入

4. 调整PBR Master的参数：
   - Metallic: 0.0
   - Roughness: 0.5

5. 预览面板会实时显示红色塑料材质

## 扩展和定制

### 添加新的节点类型

1. 在`src/types/material.ts`中添加新的NodeType
2. 在`MaterialEditor.tsx`的`getDefaultInputsForNodeType`等函数中添加配置
3. 在`NodePalette.tsx`中添加到相应分类

### 自定义着色器

修改`PreviewPanel.tsx`中的片段着色器代码以实现不同的渲染效果。
