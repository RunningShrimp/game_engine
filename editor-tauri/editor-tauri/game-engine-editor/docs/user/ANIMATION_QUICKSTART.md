# 动画时间轴编辑器 - 快速入门指南

## 5分钟上手教程

### 第一步：打开时间轴编辑器

1. 启动游戏引擎编辑器
2. 按下快捷键 `Ctrl+T` (Mac: `Cmd+T`)
3. 或点击底部状态栏的 "🎬 Timeline" 按钮

时间轴面板将出现在编辑器底部。

### 第二步：了解界面布局


### 第三步：播放控制

#### 基本播放
- `Space` - 播放/暂停
- `Home` - 跳到开始
- `End` - 跳到结束
- `← / →` - 前一帧/后一帧
- `Shift+← / →` - 前一秒/后一秒

#### 播放控制按钮
- **⏮️ 跳到开始**: 移动到动画开始位置
- **⏪ 前一帧**: 向后退一帧
- **▶️ 播放/暂停**: 开始/暂停播放
- **⏹️ 停止**: 停止并重置到开始
- **⏩ 后一帧**: 向前进一帧
- **⏭️ 跳到结束**: 移动到动画结束位置
- **🔂 循环**: 循环播放开关

#### 播放速度
- 在下拉菜单中选择速度：0.1x, 0.25x, 0.5x, 1.0x, 1.5x, 2.0x
- 1.0x为正常速度
- 低于1.0x为慢动作
- 高于1.0x为快进

### 第四步：轨道操作

#### 轨道图标说明
- **👁️ / 🚫** - 显示/隐藏轨道
- **🔒 / 🔓** - 锁定/解锁轨道（锁定后不能编辑）
- **🔇 / 🔊** - 静音/取消静音（禁用轨道）
- **▶** - 展开/收起轨道（显示子曲线）

#### 轨道颜色
- **红色** - Transform（位置）
- **绿色** - Rotation（旋转）
- **蓝色** - Scale（缩放）
- **紫色** - Property（自定义属性）
- **琥珀色** - Event（事件）

### 第五步：关键帧操作

#### 添加关键帧
1. 点击要添加关键帧的轨道
2. 在时间轴上点击位置
3. 或按 `K` 键在当前时间添加

#### 选择关键帧
- **单击** - 选择单个关键帧
- **Shift+单击** - 多选关键帧
- **拖拽** - 移动关键帧时间

#### 编辑关键帧
- **双击** - 打开属性面板编辑值
- **拖拽** - 调整时间位置
- **Delete** - 删除选中的关键帧

#### 关键帧样式
- **◇ 灰色** - 未选中
- **◆ 蓝色** - 已选中
- **◆ 红色** - 当前播放位置

### 第六步：曲线编辑

查看和编辑动画曲线：

1. 点击轨道右侧的曲线编辑器按钮
2. 查看时间-值曲线图
3. 拖拽关键帧点调整值
4. 拖拽切线手柄调整曲线形状

### 第七步：导出动画

#### 导出为JSON
1. 右键点击动画剪辑
2. 选择 "📤 导出"
3. 选择保存位置
4. 动画将保存为JSON文件

#### 导入动画
1. 点击 "➕" 按钮
2. 选择 "📥 导入"
3. 选择JSON文件
4. 动画将加载到编辑器

## 高级技巧

### 批量编辑
1. 选择多个关键帧（Shift+点击）
2. 拖拽可同时移动
3. Delete可批量删除

### 精确控制
- 使用 `← / →` 逐帧调整
- 使用 `Shift+← / →` 逐秒调整
- 在属性面板输入精确值

### 动画预览
- 调整播放速度慢放观察
- 使用循环播放重复查看
- 在关键帧之间来回跳转

### 性能优化
- 隐藏不需要的轨道
- 锁定已完成的轨道
- 使用合适的时间缩放级别

## 常见问题

### Q: 如何创建新动画？
A: 点击动画管理器的 "➕" 按钮，输入名称即可创建。

### Q: 如何复制动画？
A: 右键点击动画，选择 "📋 复制"。

### Q: 动画保存在哪里？
A: 动画自动保存为JSON文件，存储在项目的 `animations/` 目录。

### Q: 如何调整动画长度？
A: 在动画管理器中重命名动画，或修改最后一个关键帧的时间。

### Q: 支持哪些属性动画？
A: 支持所有可序列化的属性：
- Transform（Position, Rotation, Scale）
- Material属性（颜色、透明度等）
- 自定义数值属性
