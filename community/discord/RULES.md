## 核心原则

### 1. **尊重和包容**
- 尊重所有成员,不论经验水平
- 欢迎不同背景和观点
- 使用包容性语言
- 避免刻板印象和偏见

### 2. **建设性互动**
- 提供建设性反馈
- 专注于解决问题
- 认可他人的贡献
- 鼓励学习和成长

### 3. **知识分享**
- 分享有价值的资源
- 帮助他人解决问题
- 记录解决方案
- 贡献文档和示例

### 4. **专业精神**
- 保持专业态度
- 承认错误并改正
- 接受不同观点
- 以开放心态讨论

## 行为准则

### 沟通规范

#### ✅ **鼓励的行为**

1. **友善交流**
   - 使用礼貌用语
   - 表达感谢和赞赏
   - 保持耐心和理解

   示例:
   ```
   ✅ "感谢你的帮助!这解决了我的问题。"
   ✅ "这是个有趣的想法,我们可以进一步讨论。"
   ```

2. **建设性反馈**
   - 指出问题时提供解决方案
   - 关注代码和想法,而非个人
   - 解释改进建议的理由

   示例:
   ```
   ✅ "这个函数可以优化。建议使用迭代器来提升性能。"
   ✅ "我注意到这里有个潜在bug。是否考虑边界情况?"
   ```

3. **协作精神**
   - 帮助新成员
   - 分享知识和经验
   - 参与代码审查
   - 贡献文档和示例

#### ❌ **避免的行为**

1. **攻击性语言**
   - 人身攻击
   - 讽刺和嘲笑
   - 贬低他人
   - 威胁和恐吓

   示例:
   ```
   ❌ "这代码太烂了,重写吧。"
   ❌ "你根本不懂Rust。"
   ```

2. **打断和干扰**
   - 频繁打断讨论
   - 发送无关消息
   - 滥用@everyone
   - 刷屏和重复消息

3. **不尊重他人时间**
   - 不先搜索就提问
   - 不提供足够信息
   - 期望他人为你做所有工作
   - 不尊重他人的贡献

## 禁止行为

### 严重违规(立即封禁)

1. **骚扰和霸凌**
   - 针对个人的持续负面行为
   - 跟踪和监视
   - 人肉搜索
   - 性骚扰

2. **仇恨言论**
   - 基于种族、宗教、性别、性取向、残疾等的歧视性言论
   - 纳粹符号、白人至上主义等仇恨内容
   - 否认大屠杀或其他历史暴行

3. **威胁和暴力**
   - 暴力威胁
   - 自残威胁
   - 恐怖主义内容
   - 非法行为威胁

4. **非法内容**
   - 儿童色情
   - 毒品交易
   - 盗版软件
   - 任何非法活动

5. **恶意行为**
   - 黑客攻击
   - 恶意软件传播
   - 网络钓鱼
   - DoS攻击

### 中度违规(警告或禁言)

1. **垃圾信息**
   - 重复发送相同消息
   - 无意义的内容刷屏
   - 未经许可的广告
   - 大量发送链接

2. **色情内容**
   - NSFW图片或视频
   - 不适当的讨论
   - 性暗示内容

3. **政治和宗教**
   - 政治宣传
   - 宗教传教
   - 争议性话题辩论

### 轻度违规(提醒或警告)

1. **偏离主题**
   - 在技术频道讨论无关内容
   - 在 #help 聊天而非提问
   - 在 #showcase 讨论技术问题

2. **格式混乱**
   - 不使用代码块分享代码
   - 不组织长消息
   - 滥用emoji和格式

3. **不尊重他人时间**
   - 不阅读规则就提问
   - 不提供必要信息
   - 期望即时回复

## 频道使用规范

### #general (一般讨论)
- 保持友好和包容
- 避免争议性话题
- 不讨论政治和宗教
- 欢迎新成员

### #help (技术支持)
- **提问前必做:**
  1. 搜索文档和现有问题
  2. 尝试自己解决
  3. 准备最小可复现示例

- **好的提问格式:**
  ```markdown
  ## 问题标题

  **描述:** 清晰描述问题

  **环境:**
  - Rust版本: 1.75.0
  - 操作系统: macOS 14.0
  - 引擎版本: v1.2.0

  **代码:**
  ```rust
  // 最小可复现示例
  ```

  **错误信息:**
  ```
  // 完整错误信息
  ```

  **尝试过的方案:**
  1. 方案1 - 结果
  2. 方案2 - 结果
  ```

- **响应承诺:**
  - 简单问题: 24小时内
  - 复杂问题: 48-72小时内
  - 如未收到回复,可以礼貌提醒

### #showcase (作品展示)
- 只展示使用本引擎的作品
- 提供完整描述和链接
- 欢迎建设性反馈
- 鼓励互相学习和启发

### #development (开发讨论)
- 讨论引擎架构和设计
- RFC和提案讨论
- 性能优化讨论
- 需要贡献者权限

### 语音频道
- 保持对话内容得体
- 不播放大音量音乐
- 尊重频道中的其他人
- 使用"静音"功能减少噪音

## 隐私和安全

### 个人信息保护

**禁止分享:**
- 他人隐私信息
- 地址和电话号码
- 电子邮件地址(公开许可除外)
- 密码和凭证
- API密钥和令牌

**安全提示:**
- 不要在公开频道分享敏感信息
- 使用私密消息分享敏感数据
- 及时删除包含密钥的消息
- 使用环境变量管理凭证

### 账号安全

**推荐做法:**
- 启用2FA(两因素认证)
- 使用强密码
- 不与他人共享账号
- 定期检查授权应用

**泄露处理:**
如果账号被盗:
1. 立即修改密码
2. 联系版主
3. 检查并删除可疑消息
4. 吊销可疑会话

## 违规处理

### 处罚等级

#### 1级: 口头提醒
- **适用:** 初次轻微违规
- **处理:** 私聊提醒
- **记录:** 内部记录

#### 2级: 正式警告
- **适用:** 重复轻微违规或中度违规
- **处理:** 书面警告,说明违规内容和后果
- **记录:** 正式记录
- **期限:** 30天有效

#### 3级: 临时禁言
- **适用:** 警告后继续违规
- **处理:** 禁言24-72小时
- **记录:** 正式记录
- **申诉:** 可向管理团队申诉

#### 4级: 临时封禁
- **适用:** 多次违规或严重违规
- **处理:** 封禁7-30天
- **记录:** 永久记录
- **申诉:** 可提交申诉申请

#### 5级: 永久封禁
- **适用:** 严重违规或多次封禁
- **处理:** 永久移除
- **记录:** 永久记录和黑名单
- **申诉:** 通常不接受

### 处罚流程

```
违规行为
    ↓
版主发现或成员举报
    ↓
证据收集和评估
    ↓
确定违规等级
    ↓
执行处罚
    ↓
通知违规者
    ↓
记录处罚
    ↓
(可选) 申诉审查
```

### 从轻情节

以下情况可能从轻处理:
- 首次违规
- 立即承认并改正
- 配合调查
- 有良好贡献记录

### 从重情节

以下情况可能从重处理:
- 累犯(多次违规)
- 恶意意图
- 隐瞒事实
- 拒绝配合

## 举报流程

### 如何举报

如果你看到违规行为:

1. **收集证据**
   - 截图违规消息
   - 记录时间戳
   - 保存相关链接

2. **联系版主**
   - 私信任何在线版主或管理员
   - 使用举报命令(如果有机器人)
   - 发送邮件到: moderation@gameengine.dev

3. **提供信息**
   ```markdown
   **举报类型:** 违规类型
   **违规者:** @username#1234
   **时间:** 2024-12-31 12:00
   **频道:** #channel-name
   **违规消息:** [截图或引用]
   **描述:** 详细说明情况
   ```

4. **等待处理**
   - 版主会在24小时内响应
   - 可能会向你询问更多细节
   - 处理结果通常保密

### 不滥用举报

**好的举报:**
- 真实违规
- 有充分证据
- 善意举报

**滥用举报:**
- 恶意举报无辜用户
- 为报复而举报
- 伪造证据
- 滥用举报会被处罚

## 版主团队

### 谁是版主?

识别版主:
- 管理员: 红色名称
- 版主: 橙色名称
- 角色列表显示 @moderator

### 版主职责

- 执行社区规则
- 处理冲突和争议
- 回答问题
- 组织活动
- 维护友好环境

### 成为版主

**要求:**
- 积极参与至少3个月
- 良好的行为记录
- 理解项目和技术
- 有时间投入

**申请:**
1. 联系管理员
2. 说明兴趣和理由
3. 接受审查
4. 试用期为1个月
