## 写作指南

### 内容质量

1. **准确性**
   - 代码必须能运行
   - 信息必须准确
   - 事实需要验证

2. **清晰性**
   - 使用简单语言
   - 避免术语堆砌
   - 必要时解释术语

3. **完整性**
   - 提供完整上下文
   - 包含必要代码
   - 给出运行说明

### 代码示例

**好的示例:**
```rust
/// 计算两点之间的距离
///
/// # 示例
/// ```
/// use game_engine::math::distance;
///
/// let dist = distance(0.0, 0.0, 3.0, 4.0);
/// assert_eq!(dist, 5.0);
/// ```
pub fn distance(x1: f32, y1: f32, x2: f32, y2: f32) -> f32 {
    let dx = x2 - x1;
    let dy = y2 - y1;
    (dx * dx + dy * dy).sqrt()
}
```

**示例要求:**
- 包含必要的imports
- 添加文档注释
- 提供使用示例
- 说明参数和返回值

### 图表和图片

**使用图表:**
- 架构图: 展示系统结构
- 流程图: 说明工作流程
- 时序图: 展示交互过程
- 截图: 展示实际效果

**图片要求:**
- 清晰可读
- 添加说明文字
- 使用alt文本
- 合理的文件大小

### 性能数据

**提供基准:**
```rust
// 基准测试结果
Benchmark 1: 1000 iterations
  - Old: 1.2ms/iter
  - New: 0.8ms/iter
  - Improvement: 33% faster

Benchmark 2: 10000 iterations
  - Memory: Reduced from 10MB to 6MB
  - Improvement: 40% less memory
```

## 发布流程

1. **创建文章**
   - 使用本模板创建新文章
   - 保存为 `community/blog/YYYY-MM-DD-title.md`

2. **内部审查**
   - 自查上面的检查清单
   - 请团队成员审查

3. **提交PR**
   - 提交PR到主仓库
   - 等待审查和合并

4. **发布**
   - 合并后自动部署到博客
   - 在Discord #announcements 公告
   - 在Twitter/Reddit分享
